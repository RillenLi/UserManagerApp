Тестовое задание:
Написать клиент-серверное приложение.

Приложение должно осуществлять функции:
1)Авторизация пользователей.
2)Вывод в табличном виде пользователей на экран.
3)Удаление пользователя.
4)Создание пользователя.
5)Изменение пользователя (логина или пароля).

Пункт 2,3,4 доступны только после авторизации.
В качестве базы данных использовать mongoDB. 
Стандартный пользователь - login:admin password:admin.

Пароли пользователей хранить в зашифрованном виде (к примеру через md5). 
Все действия пользователей логировать.
Стилизация клиента - произвольная, но не из коробки.

Клиент должен быть на чистом js.
Сервер должен быть написан на C#
